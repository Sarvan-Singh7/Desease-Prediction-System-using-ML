# Disease Prediction System Using Machine Learning

This project prepares symptom data for disease prediction using Python, pandas, Matplotlib, and a baseline Decision Tree classifier.

## Contents

- `ML.ipynb`: data loading, cleaning, exploratory analysis, preprocessing verification, and baseline evaluation
- `Data/`: raw, training, and testing datasets
- `MasterData/`: disease descriptions, precautions, and symptom severity data

## Run the notebook

1. Open `ML.ipynb` in Jupyter Notebook or VS Code.
2. Select a Python environment with `pandas`, `numpy`, `matplotlib`, and `scikit-learn` installed.
3. Run the cells from top to bottom.

This educational project is not a medical diagnosis tool and should not replace professional medical advice.
